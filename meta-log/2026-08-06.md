# 2026-08-06

## Resident OpenAI-compatible service release candidate

- Accepted ADR 0078 and added a batch-1 resident HTTP/1.1 controller for the
  frozen seq2300 two-profile carrier. The product surface is Models, legacy
  Completions, Chat Completions, and Responses with JSON/SSE, strict request
  rejection, function tools, structured output validation, bounded Responses
  state, bearer auth, metrics, graceful drain, and stream/non-stream disconnect
  cancellation.
- Kept carrier isolation explicit: each profile/bucket owns a separate worker
  process, plugin registry, environment, compile cache scope, infer request,
  and bounded exact-token prefix-state cache. Prefix-hit evidence remains
  separate from the accepted cold/no-prefix engine lane.
- User context length is an API window, not a bucket input. The service accepts
  arbitrary prompt lengths, chooses the smallest promoted bucket, and enforces
  `prompt_tokens + requested_output_tokens <= max_context_length` with no
  truncation. A real numerical diagnostic found that non-32-aligned multi-token
  custom prefill queries are unsafe; aligned 8k/4k/2k/32 chunks plus exact
  query-one tails preserve arbitrary input without padding or token changes.
- Full startup readiness now hashes all 12 locked text-generation model files
  (`19,705,459,812` bytes) and reproduces aggregate fingerprint
  `eb05132e47fe...d7ec`; plugin and CONFIG_FILE fingerprints are independently
  checked inside every worker.
- The service closes the remaining bounded-state and cancellation gaps:
  Responses state has entry, TTL, and serialized-byte limits plus retrieve and
  delete endpoints; request deadlines cancel work; an unresponsive isolated
  worker is terminated after a grace period; streaming detokenization is
  stable across incomplete Unicode pieces; tool-call XML rejects interstitial
  garbage; and arbitrary request paths cannot create unbounded Prometheus label
  cardinality. The fast suite passes `65/65`.
- The final real-service smoke from a fresh offline-wheelhouse installation
  passes `17/17` at
  `output/http-service-smoke-max-offline-rc6-20260806/result.json`: warmed
  readiness, Chat JSON/SSE, complete Responses SSE and create/retrieve/delete
  lifecycle, state chaining, function call plus real tool-result turn, exact
  prefix-hit equivalence and bypass, resident PID stability, 33- and 8207-token
  arbitrary inputs, isolated long compact/full-logit routes, metrics, and a
  real 131072-token HTTP prompt. The maximum prompt used
  `long_compact/131072` and completed successfully; this single service
  observation is operational evidence, not a new speed claim.
- OpenAI Python SDK `2.53.0` parsed Models, Chat JSON/stream, and Responses
  create/retrieve/delete from the final controller. A checksum-verified 33-file
  native asset bundle, installable wheel, hardened systemd example, security
  policy, runtime dependency preflight, model/plugin provenance record, and
  release audit tools are present.
- A clean install exposed a release-family identity trap: public OpenVINO
  `2026.2.0` reports build `21903-52ddc073857`, while the promoted carrier is
