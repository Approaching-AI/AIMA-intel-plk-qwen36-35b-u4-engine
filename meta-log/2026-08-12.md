# 2026-08-12

## Near-boundary service regression and successor decision

An operator report dated 2026-08-11 showed that the published `v0.1.0`
service completed 2,048/4,096/8,192-token prompts but failed at actual prompt
lengths 16,380, 32,758, 65,519, and 131,037. Every failed row ended at the
final prefill output with `IQ36 LM-head runtime layout differs from the locked
contiguous contract`. The report did not include enough workload or
memory-counter detail to treat its timing rows as a formal benchmark.

The released long plugin (`01c04ced...269`) independently reproduced the exact
16,380-token failure. The scheduler reaches it through an
8192/4096/2048/32-token prefill decomposition followed by a one-token query.
At that transition, OpenVINO provides preallocated physical activation/output
buffers larger than the active logical layouts. The strict equality check was
correctly rejecting those physical layouts, but the implementation had omitted
OpenVINO's required `engine.reinterpret_buffer` step before binding arguments.

The three-file long-profile delta now reinterprets both buffers to their active
logical layouts and retains the exact f16/bfyx/linear-size assertions. The
short profile is unchanged. The fixed long plugin is 51,296,736 bytes at
SHA-256 `c0515a401f57...121`; source state is `77153ecf9ed7...067`, delta
SHA-256 is `017f5eb4925c...ed`, and an independent clean reconstruction is
bit-identical.

Targeted validation from clean commit `bf54afe` passes:

- 67/67 fast service tests;
- 18/18 real HTTP checks, including JSON/SSE, all four reported near-boundary
  lengths with status 200, and an exact 131,072-token maximum-context request;
- controlled single-run output64 measurements at all four near-boundary
  lengths, with compile, TTFT, inter-token decode rate, system memory, RSS,
  swap, prompt construction, token hashes, and runtime identities recorded;
- an eight-row full-vocabulary teacher-forced comparison at 16,380 tokens with
  top-1 agreement 8/8 and maximum KLD `0.000092598 <= 0.005`.

Decision: freeze seq2300 and `v0.1.0` as historical exact-fingerprint evidence
and disclose the broader arbitrary-length service defect. The targeted
candidate evidence closes the reproduced failure but does not transfer the
seq2300 performance claim. `v0.1.1` remains blocked on the complete 21-case
output512 ABBA8 performance/correctness/smoothness/memory gate and the repeated
runtime, packaging, security, publication, and anonymous-download gates.

Machine-readable incident and measurement data are in
`benchmarks/intel-qwen36-35b-a3b-gguf-q4km/http-near-boundary-regression-2026-08-12.json`.
