# 2026-08-10

## Public performance and correctness report

- Promoted the already-released seq2300 performance and correctness results to
  a top-level `BENCHMARKS.md` and a concise README table. No new inference run
  was needed because the engine, runtime, model, and evidence fingerprints are
  unchanged from the closed `v0.1.0` gate.
- Published all 21 paired ABBA case confidence bounds and all 21 per-case
  teacher-forced KLD/top-1 rows. The report also records exact greedy-token,
  sentinel, context smoothness, jitter, memory, and HTTP/SDK acceptance totals.
- Kept the claim boundary explicit: this is a locked-model
  inference-equivalence eval against stock OpenVINO, not an MMLU/GSM8K-style
  model-capability eval or a generic-hardware performance claim.
- Linked the canonical public Release evidence archive, its SHA-256, the raw
  rollup paths, and the versioned acceptance/model contracts so every headline
  number can be audited independently.

Decision: treat benchmark and correctness visibility as part of the public
release surface. Future releases must update `BENCHMARKS.md` from their own
checksum-bound promoted evidence rather than carrying these `v0.1.0` numbers
forward.
